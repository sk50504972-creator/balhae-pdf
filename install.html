발해 PDF 편집기 설치 안내

PDF 보기·합치기·쪽 편집·텍스트 수정·마스킹 · 파일은 내 PC 안에서만 처리됩니다

가장 쉬운 방법: 설치 도우미 윈도우 PC 추천

아래 파일을 받아 더블클릭하면 PC 앱 설치 → PDF 파일 아이콘 → PDF 기본 앱 지정 → (선택) 크롬 확장 → (선택) 구글 드라이브 연결까지 순서대로 안내합니다.

설치 도우미 받기

「Windows의 PC 보호」 창이 뜨면 [추가 정보] → [실행]을 누르세요. 크롬 또는 엣지가 깔려 있어야 합니다.

1웹에서 바로 쓰기 설치 없음

크롬·엣지에서 아래 주소를 열면 바로 씁니다. 다른 컴퓨터·노트북에서도 같습니다. 즐겨찾기에 넣어 두세요.

편집기 열기 https://balhae.claimworks.kr/balhae-pdf/

2PC 앱으로 설치 + PDF 기본 앱

  1. 아래 버튼으로 편집기를 열고 위쪽 파란 [PC 앱 설치] 버튼을 누릅니다. (안 보이면 주소창 오른쪽 설치 아이콘)
  2. 설치된 앱이 처음 열리면 「PDF 기본 앱으로 지정할까요?」가 뜹니다 → [기본 앱으로 지정].
  3. 윈도우 설정 창에서 .pdf 검색 → 지금 앱(Adobe 등) 클릭 → 발해 PDF 편집기 → [기본값 설정].
편집기 열고 설치하기

더 간단히: PDF 파일 오른쪽 클릭 → 연결 프로그램 → 다른 앱 선택 → 발해 PDF 편집기 → [항상]. PDF 아이콘이 비어 보이면 설치 도우미를 한 번 실행하면 고쳐집니다.

3구글 드라이브에서 바로 열기

  1. [드라이브에 등록하기] → 열린 창의 [구글 드라이브에 등록] → 내 구글 계정 선택 → [계속]. (계정마다 한 번)
  2. [드라이브 설정 열기] → 「앱 관리」 → 발해 PDF 편집기 「기본값으로 사용」 체크.
  3. 이제 드라이브에서 PDF 더블클릭(또는 오른쪽 클릭 → 연결 앱 → 발해 PDF 편집기)으로 열립니다. 고친 파일은 [드라이브에 저장]을 누르면 원본과 같은 폴더에 새 이름(_수정1)으로 저장되고 원본은 그대로 남습니다.
드라이브에 등록하기드라이브 설정 열기

4크롬 확장 프로그램 Adobe가 대신 뜰 때

크롬에 Adobe Acrobat 확장이 있으면 드라이브 웹·크롬에서 PDF를 가로채 Adobe로 엽니다. 발해 PDF 확장을 넣으면 크롬에서 여는 PDF가 발해 PDF로 열리고, 버튼 하나로 Adobe 확장을 끌 수 있습니다.

  1. [확장 프로그램 받기]로 받은 압축 파일을 지우지 않을 폴더(예: 문서 폴더)에 압축 풀기.
  2. 크롬 주소창에 chrome://extensions 입력 (엣지는 edge://extensions).
  3. 오른쪽 위 「개발자 모드」 켜기 → 「압축해제된 확장 프로그램을 로드합니다」 → 1번에서 푼 폴더 선택.
  4. 퍼즐 아이콘에서 발해 PDF 편집기를 고정(핀) → 아이콘 클릭 → [Adobe Acrobat 확장 끄기].
확장 프로그램 받기

설치 도우미에서 「크롬 확장도 설치할까요?」에 Y를 누르면 1번과 폴더 주소 복사를 자동으로 해 줍니다. 편집기 본체는 인터넷에서 불러오므로 확장은 다시 설치하지 않아도 늘 최신입니다.

여전히 Adobe로 열려요

① 윈도우: 위 2번의 기본 앱 지정을 확인하세요. ② 크롬·드라이브 웹: 위 4번 확장에서 Adobe 확장을 끄거나, 퍼즐 아이콘 → Adobe Acrobat ⋮ → 옵션 → 「Acrobat에서 PDF 열기」 끄기.

업데이트는 어떻게 하나요?

인터넷에 연결돼 있으면 열 때마다 최신 버전을 씁니다. 화면 오른쪽 아래에 「새 버전이 있습니다」가 뜨면 [지금 업데이트]를 누르세요. 아래쪽 버전 번호를 누르면 바로 확인합니다.

파일이 인터넷으로 올라가나요?

아니요. PDF는 내 PC 브라우저 안에서만 처리됩니다. 구글 드라이브 기능은 내가 드라이브에서 고른 파일에만 쓰입니다. 개인정보처리방침
